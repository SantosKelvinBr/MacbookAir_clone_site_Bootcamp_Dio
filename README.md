# MacbookAir Clone Site

Este projeto consiste na recriação de uma página inspirada no site da Apple, utilizando as tecnologias de **HTML**, **CSS** e **JavaScript**. É parte dos estudos realizados com base nas aulas do Bootcamp da [DIO.me](https://www.dio.me/), com o objetivo de aprimorar habilidades em desenvolvimento web.

## Funcionalidades

- Estrutura de página responsiva.
- Estilo visual semelhante ao site original da Apple.
- Implementação de interatividade com JavaScript.

## Tecnologias Utilizadas

- **HTML**: Para estruturar o conteúdo da página.
- **CSS**: Para estilizar os elementos e proporcionar um design atrativo.
- **JavaScript**: Para adicionar funcionalidade e interatividade.
